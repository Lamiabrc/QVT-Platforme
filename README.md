# QVT Box — Caneva global (1 seul site, 2 parcours)

## 1) 1 phrase (colonne vertébrale)

**QVT Box est le réseau social responsable en bulles de confiance : privé par défaut, partage choisi, sécurité d’abord — avec ZÉNA pour aider à mettre des mots et, si on le souhaite, une Luciole pour accompagner.**

## 2) Concepts clés (glossaire simple)

* **Bulle** : un espace privé (famille/proches ou entreprise) avec règles, rôles et visibilité maîtrisée.
* **Partage choisi** : 3 niveaux — **Privé** → **Référent** (Luciole/proche/manager) → **Bulle**.
* **ZÉNA** : IA émotionnelle (chat + option voix) qui aide à formuler et propose une action concrète.
* **Luciole** : adulte référent **rémunéré**, **opt‑in**, encadré (charte, limites, signalement), qui ne voit **que** ce qu’on partage.
* **Box** : option phygitale **non automatique**, proposée « quand ça compte ».
* **Mineurs** : terme utilisé uniquement pour parler des protections renforcées (adulte référent, règles, urgence).

## 5) Parcours Entreprise — canevas (/entreprise)

### Objectif

Convaincre sans peur de surveillance : utilité + agrégé + action.

### Hero

**Titre** : Prévenir l’usure, renforcer l’engagement — sans surveillance.

**Sous-titre** : Check-in simple, signaux faibles, recommandations. RH/QVT voit des tendances **agrégées**, pas des secrets individuels.

CTA : Demander une démo / Voir comment ça marche

### 3 bénéfices (cartes)

* Check-in « ça va ? » en 30 secondes
* Bulles d’équipe de confiance
* Dashboard RH agrégé et actionnable

### Comment ça marche (3 étapes)

1. Check-in individuel
2. Actions proposées (ZÉNA + rituels)
3. Vision RH/QVT agrégée + leviers

### Bloc “Ce que nous ne faisons pas”

* Pas de scoring public
* Pas de surveillance
* Pas de diagnostic médical

## 6) Parcours Vie perso — canevas (/famille)

### Objectif

Inclure tout le monde (famille/proches/aide), sans “ado” excluant.

### Hero

**Titre** : Un espace de confiance pour la vie perso.

**Sous-titre** : Bulles famille & proches : parler vrai, se soutenir, et agir. Si un **mineur** est concerné : protections renforcées (adulte référent, règles, urgence, signalement).

CTA : Créer ma bulle / Découvrir ZÉNA

### 3 bénéfices (cartes)

* Expression libre et respectueuse
* Référent (proche ou Luciole) + partage choisi
* Urgence / signalement

### Comment ça marche (3 étapes)

1. Check-in (texte/voix opt-in)
2. Partage choisi (privé/référent/bulle)
3. Action : ZÉNA + rituels + soutien (Luciole si besoin)

## 7) ZÉNA — canevas (/zena)

### Message

Parler à ZÉNA = mettre des mots + action concrète.

### Règles voix (crédibilité)

* Voix **opt-in** (push-to-talk), jamais écoute passive
* Pas de promesse médicale, pas de “diagnostic”
* Phrase obligatoire : “ZÉNA n’est pas un dispositif médical.”

## 8) Lucioles — canevas (/lucioles & /devenir-luciole)

### /lucioles (trouver une Luciole)

* Promesse : “Un accompagnement humain, doux et encadré.”
* Annuaire simple : bio, langues, disponibilités, zones, thèmes d’accompagnement
* CTA : “Choisir cette Luciole” (opt-in)

### /devenir-luciole (s’inscrire)

* Explication : rôle, cadre, rémunération, charte
* Formulaire + statut “en vérification”

### 3 règles affichées partout

* Opt-in : on choisit / on arrête quand on veut
* Encadrement : charte, limites, signalement, supervision
* Accès : la Luciole ne voit que ce qu’on partage
